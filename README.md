# 🛒 Google Merchandise Store Analysis

## 📌 Project Overview

This project analyzes the **Google Merchandise Store** dataset available in **Google BigQuery**.

The objective is to solve real-world business problems using SQL, generate actionable business insights, and build an interactive dashboard using Looker Studio.

---

## 📂 Dataset Information

- **Project:** `data-to-insights`
- **Dataset:** `ecommerce`
- **Table:** `all_sessions`
- **Total Records:** **21,493,109**

## 🎯 Key Business Insights

### Dataset

- Dataset contains **21,493,109** ecommerce session records.
- Includes customer, product, transaction, and marketing information.

### Marketing Analysis

- Organic Search generates the highest website traffic.
- Referral visitors have the highest average page views.
- Display Ads contribute comparatively low traffic.
